# NK225 MTF Report WebAPP

NK225先物の 4H / 1H / 15m チャート画像をアップロードし、Dow Theory Indicator の値を補正して、投資ナビ+用HTMLとDiscord投稿用Markdownを生成する静的Webアプリ。

## 使い方

1. `index.html` をブラウザで開く。
2. 4H / 1H / 15m のスクリーンショットをアップロードする。
3. スマホの写真/スクショアプリでテキスト認識した内容を `自動読取補助` に貼り、`貼付テキスト解析` を押す。
4. Trend Table、重要価格帯、現値、前回トレードアイデアを必要に応じて補正する。
5. `レポート生成` を押す。
6. `HTML保存` または `Discordコピー` を使う。

## 配布

サーバ処理は不要。`index.html`、`styles.css`、`app.js` を同じフォルダに置けば動作する。

同じネットワーク内にいない利用者向けには、静的ホスティングにこの3ファイルを配置する。画像はブラウザ内で読み込まれ、生成レポートにはチャート画像を埋め込まない。

## 自動処理について

- 画像ファイル名が `2026-05-08_06-02-39.png` 形式の場合、作成日時を自動反映する。
- OCRテキストから `終値` / `現値` / `現在値` を検出し、現値に反映する。
- OCRテキスト内の `SW1` / `SW2` / `SW3` 行から、トレンド、波動、転換価格、押し安値、戻り高値を反映する。
- OCRテキスト内の5桁価格を重要価格候補として抽出する。
- `前回アイデアを自動引き継ぎ` で、前回生成したトレードアイデアを次回の検証欄へ入れる。

画像そのものから完全自動で読ませる場合は、AI Vision APIまたはOCRエンジン連携が必要。

## 出力ルール

- 投資ナビ+用HTMLはスマホ最適化版
- HTML内に `table` タグを使わない
- チャート画像は埋め込まず、各時間軸に `チャート挿入：4H` などのプレースホルダーを入れる
- 前回検証とトレードアイデアはシナリオ別カードで出力する
- 髭到達と終値成立を分けて記述する
- 指定ディスクレーマーを末尾に入れる
